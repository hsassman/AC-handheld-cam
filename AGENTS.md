# Agent coordination

The user runs Codex and Claude in tandem in this repository.

- Read `AGENT_HANDOFF.md` before starting work and again before editing files.
- Record the task and intended files in your agent's section before editing.
- If another agent claims the same files, coordinate through the handoff before editing them. Claims are advisory, not file locks; re-read files before saving changes.
- Preserve other agents' and the user's uncommitted changes. Do not revert or overwrite them.
- Update your section when work completes or pauses, including changed files, validation, and any requests for the other agent.
- Keep updates concise. Only edit your own section to reduce simultaneous-write conflicts.
